# Site do DAYON - Treino

Site estático (HTML, CSS e JS puros), sem cookies, estatísticas ou conteúdo de terceiros.

- `index.html`: página inicial. `privacy.html`: privacidade.
- `api.html`: referência da API do servidor opcional, gerada por `node scripts/build-api-docs.mjs`
  a partir de `api/openapi.yaml` (não editar à mão).
- Ícones (`icon-*.png`, `favicon.ico`): gerados por `swift resources/dayon/compor-marca.swift` (rodar dentro de `frontend/`).
- `styles.css` e `site.js` vieram do site do openGym (AGPL) e foram enxugados.
